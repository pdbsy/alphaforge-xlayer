## Shared network contract

`XLAYER_TESTNET` exposes key, environment, chainId, chainIdHex, name, nativeCurrency {name,symbol,decimals}, rpcUrl, rpcUrls, explorerUrl.

`readXLayerChainConfig(env)` requires XLAYER_CHAIN=xlayer-testnet, XLAYER_CHAIN_ID=1952, XLAYER_RPC_URL and XLAYER_EXPLORER_URL. It returns network, environment, chainId, rpcUrl, rpcFallbackUrl and explorerUrl; the optional fallback defaults to the official secondary endpoint. No network calls occur.

`readXLayerLocalConfig(env)` additionally requires QP_MODE=local / QP_ADAPTER=mock, rejects NODE_ENV=production, and returns mode/adapter/realFundsEnabled plus rpcAccess=disabled. It does not unlock RPC or signing.
